# 결과 기록

## 2026-11-25 첫 실행

자료는 UCI Statlog German Credit 1,000건(우량 700, 부실 300)이다. 무작위로 600건과 400건으로 나누는 일을 30번 했다.
표본 모델은 로지스틱 회귀이고 나이, 성별·혼인 상태, 외국인 근로자 여부는 입력에서 뺐다. 승인 기준은 학습 표본의 상위 70%다.

처음에는 같은 자료의 사본(GitHub `selva86/datasets`의 `GermanCredit.csv`)으로 돌렸고, 같은 날 UCI 원본 `german.data`로 다시 돌렸다.
원본과 사본은 숫자 열 7개와 정답이 1,000행 모두 같았고, 범주 열은 부호와 말이 일대일로 대응했다. 아래 표는 원본에서도 똑같이 나왔다.

### 드리프트 (칸은 잡은 횟수/시도)

| 심은 것 | 세기 | 관행 | 보정 |
|---|---|---|---|
| 대조 | 없음 | 0/30 | 0/30 |
| 금액 배율 | 1.1 | 3/30 | 3/30 |
| 금액 배율 | 1.3 | 30/30 | 30/30 |
| 금액 배율 | 1.6 | 30/30 | 30/30 |
| 구성 변화 | 1.5 | 3/30 | 3/30 |
| 구성 변화 | 2.5 | 25/30 | 25/30 |
| 구성 변화 | 4.0 | 30/30 | 30/30 |

관행은 PSI 0.10 이상이면 올리는 것이고, 보정은 거기에 "우연으로 나올 크기가 아닐 것"을 더한 것이다.
이 표본 크기에서는 두 기준의 결과가 같았다.

표본이 작으면 달라진다(60회 반복, 금액 1.3배와 구성 2.5배만).

| 새 표본 | 기준 | 대조에서 잘못 잡음 | 금액 1.3배 | 구성 2.5배 |
|---|---|---|---|---|
| 약 100건 | 관행 | 95% | 100% | 77% |
| 약 100건 | 보정 | 7% | 35% | 60% |
| 50건 | 관행 | 100% | 97% | 68% |
| 50건 | 보정 | 7% | 7% | 43% |

보정 기준의 잘못 잡는 비율 7%는 목표 5%보다 조금 높다. 카이제곱 근사가 작은 표본에서 정확하지 않기 때문으로 보이나 따로 확인하지 않았다.

### 공정성 (칸은 주의 또는 실패가 나온 횟수/시도)

| 심은 것 | 세기 | 승인율 비 | 기회 격차 | 바꿔 넣기 |
|---|---|---|---|---|
| 대조 | 없음 | 13/30 | 10/30 | 0/30 |
| 직접 차별 | 0.05 | 28/30 | 17/30 | 30/30 |
| 직접 차별 | 0.10 | 30/30 | 22/30 | 30/30 |
| 직접 차별 | 0.20 | 30/30 | 30/30 | 30/30 |
| 간접 차별 | 0.2 | 22/30 | 14/30 | 0/30 |
| 간접 차별 | 0.4 | 27/30 | 16/30 | 0/30 |
| 간접 차별 | 0.6 | 29/30 | 21/30 | 0/30 |

실패 판정만 세면 대조는 승인율 비 5/30, 기회 격차 4/30이다.

- 바꿔 넣기는 직접 차별을 전부 잡고 대조에서 한 번도 걸리지 않았다. 간접 차별은 하나도 못 잡는다. 모델이 나이를 입력으로 받지 않으면 원리상 잡을 수 없다.
- 승인율 비와 기회 격차는 아무것도 심지 않은 모델에서도 자주 걸린다. 대조 모델의 승인율 비는 평균 0.84(0.72~0.98)였다.
  새 표본의 25세 이하는 평균 76명이고 실제 우량 비율이 58%로, 26세 이상의 73%보다 낮다.
- 그래서 결과 지표만으로는 심은 간접 차별과 자료에 원래 있던 차이를 나눌 수 없다. 다음에 풀 문제다.

### 한계

- 자료 하나, 모델 한 종류다. 시점이 없는 자료라 드리프트는 전부 심은 것이고 실제 시점 변화는 보지 않았다.
- German Credit의 성별·혼인 상태 열은 부호가 잘못 기록됐다는 지적이 있다고 알고 있으나 출처를 확인하지 않았다. 그래서 집단은 나이로만 나눴다.
- 판정 기준(PSI 0.10·0.25, 승인율 비 0.8)은 관행을 빌린 것이고 국내 규정에 적힌 숫자가 아니다.

## 2026-11-25 Home Credit (307,507건)

Kaggle 'Home Credit Default Risk'의 `application_train.csv`에서 열 21개와 나이·성별만 남겼다(`scripts/prep_home_credit.py`).
우량 282,682건, 연체 24,825건이다. 표본 모델은 나이와 성별을 입력으로 받지 않는다. 승인 기준은 상위 70%다.
신청 날짜가 없는 자료라 실제 시점 변화는 여기서도 볼 수 없다.

### 드리프트 (10회, 기준 18만 건, 새 표본 12만 건)

| 심은 것 | 세기 | 잡음 | PSI |
|---|---|---|---|
| 대조 | 없음 | 0/10 | 변수 중 최댓값 0.0004 |
| 금액 배율 | 1.1 | 0/10 | 0.038 |
| 금액 배율 | 1.3 | 10/10 | 0.247 |
| 금액 배율 | 1.6 | 10/10 | |
| 월세 거주 1.5배 | 비중 1.6% → 2.4% | 0/10 | 0.003 |
| 월세 거주 2.5배 | → 3.9% | 0/10 | 0.021 |
| 월세 거주 4배 | → 5.9% | 0/10 | 0.059 |

표본이 크면 관행 기준 0.10이 반대 방향으로 틀린다. 금액 1.1배의 PSI 0.038은 아무 변화가 없을 때(0.0004)의 약 100배라 우연이 아닌데도 통과로 나온다.
비중이 작은 범주가 4배로 늘어도 PSI는 0.10에 못 미친다.
작은 표본에서는 없는 변화를 잡고, 큰 표본에서는 있는 변화를 놓친다. 고정 기준 하나로는 안 된다는 뜻이다.

### 공정성 (8회, 칸은 평균)

25세 이하(새 표본에 평균 4,952명, 연체율 12.3% 대 7.9%)

| 심은 것 | 세기 | 25세 이하 승인율 | 그 밖 | 승인율 비 (범위) |
|---|---|---|---|---|
| 대조 | 없음 | 34.7% | 71.5% | 0.49 (0.47~0.50) |
| 직접 차별 | 0.01 | 29.3% | 71.5% | 0.41 (0.40~0.43) |
| 간접 차별 | 0.05 | 30.7% | 71.6% | 0.43 (0.42~0.44) |
| 간접 차별 | 0.2 | 21.1% | 72.0% | 0.29 (0.29~0.30) |

남성(새 표본에 평균 42,027명, 연체율 10.1% 대 7.0%)

| 심은 것 | 세기 | 남성 승인율 | 여성 | 승인율 비 (범위) |
|---|---|---|---|---|
| 대조 | 없음 | 63.3% | 73.5% | 0.86 (0.86~0.87) |
| 직접 차별 | 0.01 | 58.1% | 73.5% | 0.79 (0.79~0.80) |
| 간접 차별 | 0.05 | 57.8% | 76.2% | 0.76 (0.75~0.76) |
| 간접 차별 | 0.2 | 45.9% | 82.3% | 0.56 (0.55~0.56) |

- 아무것도 심지 않은 모델이 나이를 입력으로 받지 않는데도 25세 이하를 절반 비율로만 승인한다(비 0.49, 관행 기준으로는 실패). 근속 기간처럼 나이와 같이 움직이는 변수가 나이 노릇을 한다.
  이것이 부당한 차별인지 실제 위험 차이인지는 이 숫자만으로 정할 수 없다. 도구는 차이가 있다는 것까지만 말한다.
- 표본이 크면 비의 범위가 좁아진다. 대조 0.47~0.50과 가장 약하게 심은 간접 차별 0.42~0.44가 겹치지 않는다. German Credit에서는 겹쳐서 가르지 못했다.
- 그래서 간접 차별을 가려내려면 두 가지가 필요하다. 같은 자료로 따로 세운 기준 모델과 나란히 놓고 볼 것, 그리고 집단마다 수천 명 이상일 것.
  기준 모델과 비교하는 점검은 아직 만들지 않았다.
- 직접 차별의 세기를 0.01~0.05로 낮춘 것은 이 자료의 점수가 좁은 구간에 몰려 있어서다. German Credit의 0.05~0.20과 직접 비교할 수 없다.
- 8회, 10회 반복이고 모델 한 종류다.
