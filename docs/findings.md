# 결과 기록

## 2026-11-25 첫 실행

자료는 UCI Statlog German Credit 1,000건(우량 700, 부실 300)이다. 무작위로 600건과 400건으로 나누는 일을 30번 했다.
표본 모델은 로지스틱 회귀이고 나이, 성별·혼인 상태, 외국인 근로자 여부는 입력에서 뺐다. 승인 기준은 학습 표본의 상위 70%다.

처음에는 같은 자료의 사본(GitHub `selva86/datasets`의 `GermanCredit.csv`)으로 돌렸고, 같은 날 UCI 원본 `german.data`로 다시 돌렸다.
원본과 사본은 숫자 열 7개와 정답이 1,000행 모두 같았고, 범주 열은 부호와 말이 일대일로 대응했다. 아래 표는 원본에서도 똑같이 나왔다.

### 드리프트 (칸은 잡은 횟수/시도)

| 심은 것 | 세기 | 관행 | 보정 |
|---|---|---|---|
| 대조 | 없음 | 0/30 | 0/30 |
| 금액 배율 | 1.1 | 3/30 | 3/30 |
| 금액 배율 | 1.3 | 30/30 | 30/30 |
| 금액 배율 | 1.6 | 30/30 | 30/30 |
| 구성 변화 | 1.5 | 3/30 | 3/30 |
| 구성 변화 | 2.5 | 25/30 | 25/30 |
| 구성 변화 | 4.0 | 30/30 | 30/30 |

관행은 PSI 0.10 이상이면 올리는 것이고, 보정은 거기에 "우연으로 나올 크기가 아닐 것"을 더한 것이다.
이 표본 크기에서는 두 기준의 결과가 같았다.

표본이 작으면 달라진다(60회 반복, 금액 1.3배와 구성 2.5배만).

| 새 표본 | 기준 | 대조에서 잘못 잡음 | 금액 1.3배 | 구성 2.5배 |
|---|---|---|---|---|
| 약 100건 | 관행 | 95% | 100% | 77% |
| 약 100건 | 보정 | 7% | 35% | 60% |
| 50건 | 관행 | 100% | 97% | 68% |
| 50건 | 보정 | 7% | 7% | 43% |

보정 기준의 잘못 잡는 비율 7%는 목표 5%보다 조금 높다. 카이제곱 근사가 작은 표본에서 정확하지 않기 때문으로 보이나 따로 확인하지 않았다.

### 공정성 (칸은 주의 또는 실패가 나온 횟수/시도)

| 심은 것 | 세기 | 승인율 비 | 기회 격차 | 바꿔 넣기 |
|---|---|---|---|---|
| 대조 | 없음 | 13/30 | 10/30 | 0/30 |
| 직접 차별 | 0.05 | 28/30 | 17/30 | 30/30 |
| 직접 차별 | 0.10 | 30/30 | 22/30 | 30/30 |
| 직접 차별 | 0.20 | 30/30 | 30/30 | 30/30 |
| 간접 차별 | 0.2 | 22/30 | 14/30 | 0/30 |
| 간접 차별 | 0.4 | 27/30 | 16/30 | 0/30 |
| 간접 차별 | 0.6 | 29/30 | 21/30 | 0/30 |

실패 판정만 세면 대조는 승인율 비 5/30, 기회 격차 4/30이다.

- 바꿔 넣기는 직접 차별을 전부 잡고 대조에서 한 번도 걸리지 않았다. 간접 차별은 하나도 못 잡는다. 모델이 나이를 입력으로 받지 않으면 원리상 잡을 수 없다.
- 승인율 비와 기회 격차는 아무것도 심지 않은 모델에서도 자주 걸린다. 대조 모델의 승인율 비는 평균 0.84(0.72~0.98)였다.
  새 표본의 25세 이하는 평균 76명이고 실제 우량 비율이 58%로, 26세 이상의 73%보다 낮다.
- 그래서 결과 지표만으로는 심은 간접 차별과 자료에 원래 있던 차이를 나눌 수 없다. 다음에 풀 문제다.

### 한계

- 자료 하나, 모델 한 종류다. 시점이 없는 자료라 드리프트는 전부 심은 것이고 실제 시점 변화는 보지 않았다.
- German Credit의 성별·혼인 상태 열은 부호가 잘못 기록됐다는 지적이 있다고 알고 있으나 출처를 확인하지 않았다. 그래서 집단은 나이로만 나눴다.
- 판정 기준(PSI 0.10·0.25, 승인율 비 0.8)은 관행을 빌린 것이고 국내 규정에 적힌 숫자가 아니다.
