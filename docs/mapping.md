# 보고서의 틀과 근거

보고서는 두 문서의 틀을 빌렸다. 금융위원회 「금융분야 인공지능 가이드라인」(2026-06-22 시행)과 금융감독원 「금융분야 AI 위험관리 프레임워크」(AI RMF, 2026-06-22 최종본 배포)다.
두 문서의 원문은 구하지 못했다. 아래는 금융위 보도자료와 법무법인 해설, 언론 보도에서 확인한 내용이다.

## 공개 자료에서 확인한 것

| 내용 | 확인한 곳 |
|---|---|
| 7대 원칙: 거버넌스, 합법성, 보조수단성, 신뢰성, 금융안정성, 신의성실, 보안성 | 금융위 보도자료 |
| 신뢰성 원칙의 내용: 모델 성능 관리, 데이터 품질 확보, 공정성·편향성 점검, 설명가능성 확보 | 광장 뉴스레터, 법률신문 해설 |
| AI RMF는 거버넌스, 위험평가, 위험통제 세 영역 | 화우 뉴스레터, 언론 보도 |
| 위험평가는 합법성 20%, 신뢰성 30%, 신의성실 20%, 보안성 30%, 세부 항목 16개 | 광장 뉴스레터, 보험저널 |
| 25점 미만 저위험, 25점 이상 50점 미만 중위험, 50점 이상 고위험, 75점 이상은 출시 재검토 | 같은 곳 |
| 대출 심사 등 개인의 권리·의무에 중대한 영향을 미치는 AI는 점수와 무관하게 고위험 | 전자신문, 화우 뉴스레터 |
| 고위험: 의사결정기구 사전 승인, 제3자 평가·검증, 운영 모니터링 강화. 저위험: 승인 절차 간소화 | 광장 뉴스레터, 전자신문 |
| 두 문서 모두 법적 강제력이 없는 자율규제 | 금융위 보도자료, 언론 보도 |

## 이 도구의 해석

- 점검을 신뢰성 원칙의 네 영역에 이렇게 붙였다. AUC 유지와 강건성(입력 1% 변화) → 모델 성능 관리, PSI → 데이터 품질, 공정성 점검 네 가지 → 공정성·편향성. 거절 사유의 충실도·일관성 → 설명가능성.
  원문이 각 영역에서 무엇을 재라고 하는지는 확인하지 못했으므로 이 대응은 해석이다.
- 판정 기준 숫자는 규정에서 온 것이 아니다. PSI 0.10·0.25와 승인율 비 0.8은 관행이고, AUC 하락 0.03·0.05, 기준 모델 차이 2%p·5%p, 뒤집힘 비율 2%·5%, 사유 충실도 90%·50%, LLM 판정 기준은 이 도구가 정했다.
- LLM 보고서에서 숨긴 지시문 추종을 보안성 원칙에 붙였다. 법률신문 해설이 보안성 원칙의 대응 대상으로 프롬프트 인젝션을 든다.
- 종합 판정은 영역별 판정 중 가장 나쁜 것이다. 검사하지 않은 영역은 통과로 치지 않고 따로 적는다.

## 이 도구가 하지 않는 것

- 위험점수를 내지 않는다. 16개 세부 항목의 이름과 배점을 확인하지 못했고, 합법성·신의성실·보안성은 이 도구가 재는 대상이 아니다.
  회사가 낸 점수를 `--risk-score`로 넣으면 등급 구간에 맞춰 적기만 한다.
- 중위험 등급의 통제 내용은 공개 자료에서 확인하지 못했다.
- 미국 SR 26-2와의 대응은 아직 없다.
