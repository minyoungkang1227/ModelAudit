# 점검 항목과 규제 항목

| 점검 | 닿는 항목 | 근거로 읽은 것 |
|---|---|---|
| 드리프트 | 금융위 「금융분야 인공지능 가이드라인」(2026-06-22 시행) 7대 원칙 중 ④ 신뢰성 | 해설 기사: 모델 성능·데이터 품질·편향성을 정기적으로 점검 |
| 공정성 | 같은 원칙 ④ 신뢰성 | 같은 기사 |
| 두 점검 모두 | 금감원 AI RMF의 위험평가·위험통제 | 보도: 거버넌스, 위험평가, 위험통제 세 부문. 운영 단계 모니터링 |

7대 원칙은 거버넌스, 합법성, 보조수단성, 신뢰성, 금융안정성, 신의성실, 보안성이다.

가이드라인과 AI RMF의 원문은 읽지 못했다. 위 표는 금융위 보도자료의 요약 표와 법률신문 해설 기사만 보고 맞춘 것이다.
원문의 세부 항목 번호까지 맞추는 일과 위험등급 산정은 아직 하지 않았다. 미국 SR 26-2와의 대응도 아직 없다.
